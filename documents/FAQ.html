    FAQ (Часто задаваемые вопросы)

    Общие вопросы

    Как добавить собственный уровень логирования?

    Вы можете определить любые строковые уровни в LoggerLevels. Например:

    const levels = {
      levels: { trace: -1, debug: 0, info: 1, warn: 2, error: 3, fatal: 4 },
      level: "info",
    };

    Почему мои сообщения не записываются в файл?

    Проверьте:

    • Убедитесь, что writeFile: true передан в контексте вызова или в baseContext.
    • Проверьте права на запись в директорию.
    • Файл создаётся автоматически при первом вызове write, если директория существует.

    Как изменить разделитель между частями сообщения?

    Используйте separator в контексте:

    await logger.execute("Сообщение", {
      context: { level: "info", separator: " | " },
    });

    Работа с временными метками

    Как отключить временные метки?

    const timestampService = new TimestampService();
    timestampService.disable();

    Или в конструкторе можно сразу выключить:

    const timestampService = new TimestampService();
    timestampService.turn(false);

    Как изменить формат временной метки?

    Передайте свою функцию форматирования:

    const timestampService = new TimestampService({
      formatter: (date) =>
        date.toLocaleString("ru-RU", { timeZone: "Europe/Moscow" }),
    });

    Как добавить квадратные скобки вокруг временной метки?

    По умолчанию TimestampWrapper уже добавляет скобки. Если вы хотите изменить обёртку, создайте свой класс, реализующий WrapperType, или используйте EmptyWrapper для отключения обёртки:

    const timestampService = new TimestampService({
      wrapper: new EmptyWrapper(),
    });

    Форматирование

    Как добавить свой форматтер для специфических данных?

    Наследуйте BaseFormatter и реализуйте canFormat и format. Затем подключите через FormatterHandler.

    Пример см. в разделе Расширение и кастомизация.

    Почему мои ошибки выводятся как [Object object]?

    Используйте ErrorFormatter, который автоматически обрабатывает ошибки в стандартном наборе форматтеров. Если вы заменили formatterHandler, добавьте ErrorFormatter в цепочку.

    Как обработать null и undefined?

    NullableFormatter преобразует их в строки "null" и "undefined". Он также входит в стандартный набор.

    Пользовательский ввод (метод read)

    Как изменить префикс для пользовательского ввода в файле?

    При создании логгера укажите userInputSettings:

    const logger = new Logger({
      // ...
      userInputSettings: {
        prefix: "Input:",
        separator: " ",
      },
    });

    Как обработать случай, когда пользователь ничего не ввёл?

    Метод read возвращает пустую строку, если пользователь нажал Enter без ввода. Вы можете проверить это самостоятельно.

    let userInput = "";
    while (!userInput.trim()) {
      userInput = await logger.read("Введите ваше имя (обязательно):", {
        context: { level: "info" },
      });
      if (!userInput.trim()) {
        console.log("Имя не может быть пустым. Попробуйте снова.");
      }
    }
    console.log(`Привет, ${userInput}!`);

    Как добавить обработку нажатия Ctrl+C?

    В Node.js вы можете использовать обработчик события SIGINT. Это не входит в библиотеку, но вы можете обернуть вызов read:

    process.on("SIGINT", () => {
      console.log("\nВвод прерван");
      process.exit();
    });

    const result = await logger.read("Введите текст:", {
      context: { level: "info" },
    });

    Производительность

    Влияет ли запись в файл на производительность?

    Запись в файл происходит асинхронно через поток в режиме append, что минимизирует блокировку. Однако для высоконагруженных систем рекомендуется использовать отдельный поток или буферизацию.

    Можно ли использовать логгер в браузере?

    Нет, библиотека использует Node.js API (fs, process). Для браузера потребуется отдельная адаптация.

    Ошибки и исключения

    Что делать, если FileService не может создать файл?

    Убедитесь, что у процесса есть права на запись в указанную директорию. FileService автоматически создаёт директорию, если её нет, но только если родительская директория существует и доступна для записи.

    Почему логгер выбрасывает ошибку при повторном вызове read?

    Метод read блокирует поток ввода до завершения. Если попытаться вызвать его повторно до завершения первого, будет выброшена ошибка. Дождитесь завершения предыдущего вызова.

    Кастомизация

    Как изменить имя логгера в префиксе?

    Укажите name в конструкторе:

    const logger = new Logger({
      name: "MyApp",
      // ...
    });

    Можно ли использовать несколько логгеров с разными настройками?

    Да, создайте несколько экземпляров с разными конфигурациями.

    Как добавить суффикс вместо префикса?

    Вы можете создать свой аффикс, унаследовав BaseAffix с типом suffix:

    class MySuffix extends BaseAffix {
      public constructor(data: AffixChildConstructor) {
        super({ type: "suffix", ...data });
      }
    }

    Затем подключите его в AffixHandler.

    Совместимость

    Какие версии Node.js поддерживаются?

    Минимальная версия — 7.6.0 (из-за использования async/await и fs/promises). Рекомендуется использовать LTS-версии Node.js.

    Поддерживается ли TypeScript?

    Да, библиотека написана на TypeScript и поставляется с полной типизацией.

    Дополнительные вопросы

    Где найти примеры использования?

    В разделе Быстрый старт и в тестах проекта (если есть).

    Можно ли использовать логгер без записи в файл?

    Да, просто не передавайте fileService в конструктор.

    Как скрыть вывод в консоль?

    Установите log: false в контексте:

    await logger.execute("Секретно", {
      context: { level: "info", log: false, writeFile: true },
    });

    Как добавить дополнительные данные в сообщение?

    Вы можете передать любой объект в input, если он реализует toString() или если вы добавили кастомный форматтер для его обработки.
