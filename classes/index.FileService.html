    Class FileService

    Сервис для работы с одним файлом: чтение, запись (добавление в конец), перезапись, удаление, проверка существования.

    Создаёт поток записи в режиме 'append' и автоматически создаёт директорию, если её нет.

    Example

    const fileService = new FileService({ filePath: './logs/app.log' });
    await fileService.write('Log entry');
