    Class TimestampService

    Сервис для генерации строковых представлений текущего времени. Может быть использован для логирования, именования файлов и других задач.

    Example

    const ts = new TimestampService({
      formatter: (date) => date.toLocaleString('ru-RU'),
    });
    console.log(ts.execute()); // "29.03.2025, 12:34:56"
